# M3-Browser
A modern Android web browser built with Material 3 Expressive, designed for a clean and customizable browsing experience.

Features include:

- Material 3 Expressive interface
- Customizable search engine and homepage
- Mobile and desktop User-Agent presets
- JavaScript, cookies, DOM Storage, and media controls
- WebView pre-rendering and instant back/forward navigation
- Adjustable page zoom
- Developer and WebView tools
- Tab support and session restoration
